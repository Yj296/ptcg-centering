# PTCG卡片居中量化检查工具

PTCG（宝可梦集换式卡牌）卡片居中量化检查工具 · Web 版

单文件网页应用，内嵌 OpenCV.js 图像引擎，完全离线可用，支持在 Windows / macOS / iPhone / 安卓等设备的浏览器中直接使用。

## 功能

- 导入卡片照片（自动缩放大图）
- 外框矫正：手动定位 4 条外边（每边 2 点），自动透视矫正
- 内框测量：手动定位 4 条内参考线，量化左右/上下边距与比例
- 评级参考：PSA / BGS / CGC 居中评级上限
- 图片调节：对比度调节（0.3 ~ 2.5）
- 辅助功能：背景锁定、导航十字线、定位点微调、画面跟随、撤销/重置

## 在线使用

打开即可使用，无需安装：

https://yj296.github.io/ptcg-centering/

## 使用流程

1. 导入照片
2. 调整图片位置 / 旋转（旋转功能已替换为对比度调节）
3. 锁定背景（可选）
4. 轻点图片定位 → 方向键微调 → ✓落点，依次添加外框 4 条边、内框 4 条参考线
5. 点击「显示结果」查看量化分析与评级

## 本地使用

将 `index.html` 下载到本地，用浏览器打开即可（建议 Safari / Edge / Chrome）。
